# Paper figure sources

All six PNG/PDF pairs in this directory are generated by
`generate_paper_figures.py`, saved alongside the figures. They use a shared
6.4-inch publication width and consistent, page-scaled typography. Run from
the repository root:

Plots are title-free; the manuscript captions carry descriptive context.
Legends sit in a shared margin above the panels, outside the data areas.

```bash
python docs/figures/generate_paper_figures.py --figure all
```

To regenerate one figure, pass its number with `--figure` (for example,
`--figure 5`). The script reads the recorded data and fit outputs and does not
rerun any fits. The `plot_wfi02_*.py` files are per-figure entry points into
this same generator; their plotting implementations are not duplicated.

| Figure | Source function |
| --- | --- |
| 1 — Spectral coverage | `plot_spectral_coverage` |
| 2 — Raw and corrected RCS | `plot_raw_corrected` |
| 3 — Ice-thickness history and deposition rate | `plot_ice_history` |
| 4 — RCS data and model fits | `plot_rcs_model_data` |
| 5 — CAR201 data and model predictions | `plot_car201_model_data` |
| 6 — Ice-free complex reflection | `plot_complex_reflectance` |

Rebuild the manuscript PDF with the checked-in Pandoc/XeLaTeX command:

```bash
bash docs/build_wfi_tmm_paper.sh
```
