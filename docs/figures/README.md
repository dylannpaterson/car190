# Paper figure sources

All seven PNG/PDF pairs in this directory are generated by
`generate_paper_figures.py`, saved alongside the figures. They use a shared
6.4-inch publication width and consistent, page-scaled typography. Run from
the repository root:

Plots are title-free; the manuscript captions carry descriptive context.
Legends sit in a shared margin above the panels, outside the data areas.

```bash
python docs/figures/generate_paper_figures.py --figure all
```

To regenerate one figure, pass its number with `--figure` (for example,
`--figure 5`). The script reads the recorded data and fit outputs and does not
rerun any fits. By default, it uses the completed 20261117 relative-response
pipeline run. The `plot_wfi02_*.py` files are per-figure entry points into this
same generator; their plotting implementations are not duplicated.

To regenerate the paper figures from a completed relative-response pipeline
run, pass its pipeline output root (or its date root). For example:

```bash
python docs/figures/generate_paper_figures.py \
  --run-root 20261117/production/pipeline_runs/relative_response \
  --figure all
```

The run manifest supplies the raw/corrected statistics input root used by
Figure 2. Figures 3--7 read production fits and the modulated bundle from the
selected run. The command writes seven figure pairs to `docs/figures`; use
`--output-dir` to direct a comparison run elsewhere. The per-figure wrapper
scripts accept the same run-selection options.

The all-detector metric analysis accepts the same pipeline output/date root and
can restrict an in-progress run to completed detectors with repeatable
`--detector` options:

```bash
python docs/analyze_wfi_all_detector_metrics.py \
  --run-root 20261117/production/pipeline_runs/relative_response \
  --detector WFI02 \
  --output-dir 20261117/production/pipeline_runs/relative_response/analysis
```

| Figure | Source function |
| --- | --- |
| 1 — Spectral coverage | `plot_spectral_coverage` |
| 2 — Raw and corrected RCS | `plot_raw_corrected` |
| 3 — Ice-thickness history and deposition rate | `plot_ice_history` |
| 4 — RCS data and model fits | `plot_rcs_model_data` |
| 5 — CAR201 data and model predictions | `plot_car201_model_data` |
| 6 — Ice-free complex reflection | `plot_complex_reflectance` |
| 7 — Focal-plane ice thickness at segment ends | `plot_focal_plane_ice_thickness` |

Figure 4 generation also writes `wfi02_rcs_likelihood_by_led.csv`; Figure 5
generation writes `wfi02_car201_residual_metrics.csv`. These summarize the saved
fits over all 256 WFI02 tiles and the full WFI02 stellar sample, respectively.
In both files, the log-likelihood difference is Joint RCS + stellar minus
RCS-only TMM and a positive value favors Joint RCS + stellar; the CAR201 value
is per measurement and the RCS value is per LED/tile/observation group. The CAR201 mean Student-$t$ NLL
columns omit additive constants that cancel in the likelihood difference.

Rebuild the manuscript PDF with the checked-in Pandoc/XeLaTeX command:

```bash
bash docs/build_wfi_tmm_paper.sh
```
